# Kingrane — portfolio

Портфолио на Next.js: непрерывная WebGL-сцена от чёрной дыры до ночного сада, HTML-контент поверх неё и 13 проектных ASCII-обложек.

## Разработка

```powershell
npm run dev
```

Статический экспорт — `npm run build`, результат в `out\`. Деплой на GitHub Pages через `.github\workflows\deploy.yml`. Изменения ведутся в `redesign`; push выполняется только по отдельной команде.

## Устройство

- `src\content\projects.ts` — названия, согласованные описания, технологии и ссылки; счётчики фильтров вычисляются из данных.
- `src\scene\timeline.ts` — плавное состояние мира, привязанное к фактическим секциям страницы.
- `src\components\webgl\` — один persistent WebGL canvas: физический интегратор дыры, отдельные резкие звёзды, созвездия, цветы, светлячки и четыре монарха.
- `src\components\projects\project-cover.tsx` — 13 разных Canvas2D-сцен, 16:10, ограничение 30 fps и остановка невидимых обложек.
- `src\scene\reading-zones.ts` — защита HTML-текста; RGB coverage сада разделяет лепестки, чистые сердцевины и временный полный ASCII при посадке.

В v3 добавлены фиолетовый диск, горизонтальный скан, дождь после падения через стек и проекты, неравномерное бенто, сад с низкими цветами по всей ширине и плавным scroll-параллаксом. Футер v2 сохранён. Нативный скроллбар оформлен округлой лавандовой «таблеткой».

## Отладка сцены

- `?ascii=full` — диагностический полный ASCII; не пользовательский переключатель оформления.
- `?tune` — шесть параметров: микс, gain, glow, desktop/mobile ячейки и dither; есть сброс. Настройки не сохраняются в localStorage.
- По умолчанию ячейки 10/11 CSS px, gain 1.5, glow 0.12, Bayer 8×8. До восьми экранных источников; две бабочки оставляют по 20 позиций следа на 1.5 секунды.

При reduced-motion, Save-Data или отсутствии WebGL2 используются существующие статичные постеры; обложки проектов рисуют неподвижный кадр. Во время скрытой вкладки анимация останавливается. Автодеградация снижает разрешение дыры, затем детали/количество объектов и только на нижнем уровне упрощает ASCII-сэмплирование.

## Статус проверок

**Для публикации `020d33f` пользователь разрешил production build: `npm ci` и `npm run build` успешно выполнены в изолированной рабочей копии.** Компиляция, встроенный TypeScript и статический экспорт прошли. Lint, отдельный QA, браузер, новые скриншоты и измерения не запускались; визуальное/runtime-подтверждение B–D остаётся открытым. Свежий `out\` находится в рабочей копии публикации; экспорт в основной папке проекта не пересобирался. Подробнее — [отчёт публикации](reports/v3-publication.md).

- [Итоговый статус v3](reports/v3-status.md): реализация отдельно от неподтверждённых критериев.
- [Архив фазы A](reports/v3-phase-a/README.md): старые доказательства ASCII-ядра, **не** новых дыры/бенто/сада.
- FPS ≥55/≥30, Lighthouse ≥85 и CLS <0.05 — цели, не полученные результаты. Доля янтаря, площадь свечения, новый контраст и отсутствие швов также не измерены.
- Постеры в `public\scene\` сохранены от фазы A; новые live-визуалы с них не оценивать.

QA-скрипты подготовлены для будущего разрешённого прогона против свежего, уже собранного и обслуживаемого экспорта: `scripts\qa.ts` (геометрия, контраст, швы), `qa-ascii.ts` (ядро/DPR/tune), `qa-effects.ts` (обложки, фильтры, все строки сада и кадры посадок), `qa-smoke.ts` (fallback), `qa-performance.ts` (измерения производительности). Сами скрипты сервер не запускают и экспорт не собирают.

Несогласованные полные описания и старые черновики остаются в [COPY_TO_APPROVE.md](COPY_TO_APPROVE.md), не в интерфейсе.
