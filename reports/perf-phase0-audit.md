# Фаза 0 — статическая проверка гипотез (не оптимизации)

База `27da66a`; поведение здесь описано по коду, а не выдано за измеренную экономию.
Числа нагрузок и порядок приоритетов — в `PERF_REPORT.md` после живых прогонов.

| Пункт | Что найдено | Статус / ограничение |
|---|---|---|
| §3.1 частота | R3F всегда рендерит в видимой вкладке; Lenis и Cursor имеют отдельные постоянные RAF. Reading zones — отдельная событийная RAF, marquee refresh 12.5 Hz. | Общего 60 Hz limiter и idle ambient 30 Hz нет. Не менять до обсуждения baseline. |
| §3.1 разрешение | Основной DPR ограничен 1.8 desktop / 1.4 narrow, при q<0.5 умножается на 0.7, минимум 1. Дыра: CSS размеры × 0.75 × max(0.45,q), независимо от DPR. | Не переключено на DPR 1: изменение разрешения требует diff. HTML DPR остаётся нативным. |
| §3.2 проходы | Отдельные World Render, ASCII, общий финальный tone/contrast/dither. Дополнительно отдельные hole MRT, stars layer и garden coverage. | Bloom отсутствует, удалять нечего. Слияние проходов пока только идея. |
| §3.2 настройки | Canvas: antialias=false, stencil=false, high-performance; depth=true для 3D. Composer: multisampling=0, FP16. Дыра: FP16 MRT count=2, без depth/stencil/mipmaps, LinearFilter. | Нельзя назвать все FP16 лишними: дыра содержит HDR. Количество ресурсов не равняется VRAM bytes. |
| §3.3 скрытая дыра | `Blackhole`: при worldState.hole≤0.001 mesh invisible и return ДО renderer.render. | Пропуск уже реализован; проверить отсутствие GPU query этого прохода после hero. |
| §3.3 лучи | horizon r²≤1, escape r²>576 с наружной скоростью, transmission<0.008, фиксированный максимум цикла 96, адаптивный dt≤2.8. Есть аналитическое дальнее поле при b>10.5 и blend 9.5…10.5. | Эти пункты уже присутствуют, не объявлять их будущей новой оптимизацией. |
| §3.3 шум/звёзды | В disk: 2/3 noise вызова с sin/cos/atan/exp/pow; два процедурных star layers, при сильном отклонении выборка соседних клеток 3×3. | Timer query измеряет весь shader-pass, не отдельные функции GPU. Их стоимость внутри прохода отдельно не доказана. Noise texture/cubemap/LUT не добавлены. |
| §3.3 LUT/precision | LUT отсутствует; highp float/int, steps clamp 32…96. | LUT только отдельный эксперимент `?lut` после разрешения. Precision/hash изменения также могут менять изображение. |
| §3.4 сад | InstancedBufferGeometry для стеблей, листьев, лепестков, сердцевин; объединённый mesh бабочек и Points светлячков. Ветер/крылья уже в vertex shader; центры бабочек аналитически на CPU. | Цель «десятки draw calls» проверяется живыми counters. Не сотни независимых цветов. |
| §3.4 прозрачность/culling | Петали transparent=true, DoubleSide, forceSinglePass, meshes frustumCulled=false; отдельная coverage-сцена. Есть coarse visibility/early return по flowers/growth. | Нет distance LOD; screen-door не применён. bounds и сортировку нельзя менять вслепую. |
| §3.4 матрицы | Coverage group matrixAutoUpdate=false; статике в целом этот флаг не выставлен. Garden projects CPU anchors и reading protection обновляются в useFrame. | Проверить CPU Garden по профилям, а не переносить всё на GPU без доказательства. |
| §3.5 фоны | NightSky — один fullscreen shader, rain/streak — существующий world; нет набора отдельных fbm-фонов с одновременным смешиванием пяти пресетов. | Не добавлять несуществующую архитектуру «ради оптимизации». |
| §3.5 ASCII | Эмиттеры 8; нулевые радиус/strength пропускаются внутри цикла. Trail-цикл запускается по uTrailActive. | Глобального bounding early-out для всех радиусов нет. Потенциальная экономия только после timer/diff. |
| §3.6 CSS | В CSS-модулях нет backdrop-filter/filter:blur/mix-blend-mode. В карточках transition включает box-shadow; курсор transition width/height. will-change:transform только при data-tilting. | Нет основания заменять nonexistent blur. box-shadow/size transitions — реальные гипотезы; нужны trace и визуальная проверка. |
| §3.6 layout reads | Reading zones кеширует строки на layout, НО делает getBoundingClientRect каждого видимого semantic text при scroll/update; маска перерисовывается Canvas2D. Marquee bounding read на pointer event. Карточка rect кешируется при enter и сбрасывается scroll. | Цель «ни одного layout read в кадре» ещё не выполнена. Сам rect read не всегда forced layout — доказательство в trace. |
| §3.6 React | Pointer/scroll координаты в mutable store. Cursor setVariant на смене hover, PerformanceMonitor setQuality при переходе качества. Секции reveal используют Motion. | Отдельный React profiling build не добавлялся; production trace не доказывает точное число React commits. |
| §3.6 contain | content-visibility/contain-intrinsic-size отсутствуют. Marquee движение CSS transform. | containment может изменить rect/cache/маски и требует full diff, не применяется в Фазе 0. |
| §3.7 обложки | 13 детальных Canvas2D неподвижны: один draw после font ready и появления, потом только resize. Общий одноразовый RAF Set отдаёт по одной обложке за кадр и останавливается. Atlas и typed buffers; getImageData/putImageData нет. | Не возвращать hover/30 Hz анимацию. Uint32 ImageData рецепт не подходит: здесь glyph atlas drawImage, не pixel ImageData. Первичный draw всё ещё может дать микрофриз. Worker не добавлен. |
| §3.8 жизнь ресурсов | useEffect cleanup dispose явных geometries/materials/targets/textures; Garden создаёт ресурсы заново. Hidden tab ставит Canvas frameloop=never; webglcontextlost preventDefault. | Пять циклов проверяют счётчики/heap, не доказывают отсутствие ВСЕХ утечек. StrictMode double mount и реальная context loss отдельно не проверены; recover не переписан. |
| §3.8 аллокации | В useFrame в основном refs/reuse; butterfly vectors переиспользуются; DOM/renderer/reading-mask paths могут аллоцировать. Диагностика ?perf намеренно пишет samples в массивы. | Allocation sampling/GC включают overhead диагностики. Их нельзя выдать за чистые allocation bytes сайта. |
| §3.8 деградация | PerformanceMonitor bounds desktop [55,60/90] / narrow [30,55], flipflops=3; q меняет hole resolution, steps/counts/DPR. | Не переделывали порядок/гистерезис; baseline записывает реальные quality. Профиль normal hardware без деградации ещё надо проверить. |
| §3.9 загрузка | Единая сцена dynamic ssr:false после requestIdleCallback(timeout=2500) / timeout700; сад и футер статически входят в lazy scene. Есть namespace imports Three. compile/precompile warmup отсутствует. | Analyzer должен показать фактическое tree shaking: namespace import сам по себе не доказательство лишнего бандла. First-use shader stutter не исключён прогревом измерений. |
| §3.9 ассеты/fallback | next/font latin+cyrillic swap, хэшированные Next ассеты; static export, unoptimized images; ScenePoster для reduced-motion/Save-Data/no WebGL2. | Ассеты/шрифты/постеры не пережаты и не заменены в Фазе 0. |

Источники: `src/components/webgl/scene.tsx`, `scene-root.tsx`, `worlds/blackhole.tsx`, `worlds/garden.tsx`, `worlds/butterflies.tsx`, `shaders/blackhole.ts`, `shaders/ascii.ts`, `effects/world-post.tsx`, `src/scene/reading-zones.ts`, `src/components/ui/{cursor,smooth-scroll,marquee}.tsx`, `src/components/projects/{project-card,project-cover}.tsx`, `src/app/layout.tsx`.
